Row ID Copier

Copies the identifier from the row you have selected on the page, straight to your clipboard.

row-id-copier-1.0.0.zip · 4 KB
Installer (Windows) Zip

Install or update with the installer (Windows)

  1. Option A: press Win+R, paste this line, and press Enter: 
    powershell -NoProfile -ExecutionPolicy Bypass -Command "$x='row-id-copier'; irm https://jasonkbarry.github.io/extensions/install.txt | iex"

    Option B: download Install-RowIDCopier.zip, right-click it and choose Extract All, then double-click the .cmd file inside. If Windows warns you, click More info → Run anyway.
  2. First time: it installs to %LOCALAPPDATA%\Nextiva Extensions\row-id-copier, copies that path to your clipboard, and opens chrome://extensions. Turn on Developer mode and click Load unpacked. In the folder window, click the address bar, press Ctrl+V then Enter, and click Select Folder.
  3. Updates: run it again. It finds where Row ID Copier is already installed in Chrome or Edge, even a folder you chose yourself, and copies the new version there with your settings kept. Then click the reload arrow on Row ID Copier in chrome://extensions.

Install manually

  1. Download the zip, then right-click it and choose Extract All. Move the extracted row-id-copier folder somewhere it can stay, such as Documents. Chrome keeps loading it from there.
  2. In Chrome, go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the row-id-copier folder.
  4. Click the puzzle-piece icon in the toolbar and pin Row ID Copier so it's easy to reach.

Use

  • Select a row on the page, then click the Row ID Copier toolbar icon, or press Ctrl+Q.
  • The row's identifier is copied to your clipboard, and a small confirmation shows what was copied.
  • If it copies the wrong value, right-click the icon and open Options to point it at the right column.

By default it reads the first column of the selected row. In Options you can choose the column by position, by header name, by a custom selector, or from a row attribute.

Updating

Easiest: run the installer again (Win+R command or zip above), then click the reload arrow in chrome://extensions. Or by hand: Download the new zip, extract it, and copy its files over your existing folder. Then click the reload arrow on the extension in chrome://extensions.

Works in Google Chrome and Microsoft Edge.
