Contact Center Guard

Protects calls on the Nextiva Contact Center agent screen.

contact-center-guard-1.6.zip · 6 KB
Installer (Windows) Zip

Install or update with the installer (Windows)

  1. Option A: press Win+R, paste this line, and press Enter: 
    powershell -NoProfile -ExecutionPolicy Bypass -Command "$x='contact-center-guard'; irm https://jasonkbarry.github.io/extensions/install.txt | iex"

    Option B: download Install-ContactCenterGuard.zip, right-click it and choose Extract All, then double-click the .cmd file inside. If Windows warns you, click More info → Run anyway.
  2. First time: it installs to %LOCALAPPDATA%\Nextiva Extensions\contact-center-guard, copies that path to your clipboard, and opens chrome://extensions. Turn on Developer mode and click Load unpacked. In the folder window, click the address bar, press Ctrl+V then Enter, and click Select Folder.
  3. Updates: run it again. It finds where Contact Center Guard is already installed in Chrome or Edge, even a folder you chose yourself, and copies the new version there with your settings kept. Then click the reload arrow on Contact Center Guard in chrome://extensions.

Install manually

  1. Download the zip, then right-click it and choose Extract All. Move the extracted contact-center-guard folder somewhere it can stay, such as Documents. Chrome keeps loading it from there.
  2. In Chrome, go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the contact-center-guard folder.
  4. Check that Contact Center Guard is turned on. It has no toolbar button; it works on its own on the agent screen.

What it does

  • Back: always blocked on the agent screen (toolbar Back, Alt+Left, mouse back button), with a popup explaining why.
  • Refresh: F5 or Ctrl+R shows a warning first. Press it again within a minute to refresh anyway.
  • Callbacks: on an Outbound Call / In review, choosing a disposition first shows a reminder to call the customer back. Try again to continue without calling.

Closing the tab, typing a new address and Chrome's toolbar Reload button are not blocked. If you also have Callback Disposition Guard installed, turn it off; this extension includes its callback reminder.

Updating

Easiest: run the installer again (Win+R command or zip above), then click the reload arrow in chrome://extensions. Or by hand: Download the new zip, extract it, and copy its files over your existing folder. Then click the reload arrow on the extension in chrome://extensions.

Works in Google Chrome and Microsoft Edge.
