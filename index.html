Chrome extensions for the Nextiva Contact Center. Use the installer to set up or update them, or open an extension for its install steps.

Install or update everything

One step for all the extensions below (Windows). Press Win+R, paste this, and press Enter, or download the zip and run the .cmd inside. It updates the ones you have, wherever they're installed, and sets up any new ones.

powershell -NoProfile -ExecutionPolicy Bypass -Command "$x='all'; irm https://jasonkbarry.github.io/extensions/install.txt | iex"
