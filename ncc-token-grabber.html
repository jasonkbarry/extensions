NCC Token Grabber

Reads the NCC/Thrio session token from the tab you have open and copies it, with your tenant info, to your clipboard.

Installer (Windows) Zip

Install or update with the installer (Windows)

  1. Option A: press Win+R, paste this line, and press Enter: 
    powershell -NoProfile -ExecutionPolicy Bypass -Command "$x='ncc-token-grabber'; irm https://jasonkbarry.github.io/extensions/install.txt | iex"

    Option B: download Install-NCCTokenGrabber.zip, right-click it and choose Extract All, then double-click the .cmd file inside. If Windows warns you, click More info → Run anyway.
  2. First time: it installs to %LOCALAPPDATA%\Nextiva Extensions\ncc-token-grabber, copies that path to your clipboard, and opens chrome://extensions. Turn on Developer mode and click Load unpacked. In the folder window, click the address bar, press Ctrl+V then Enter, and click Select Folder.
  3. Updates: run it again. It finds where NCC Token Grabber is already installed in Chrome or Edge, even a folder you chose yourself, and copies the new version there with your settings kept. Then click the reload arrow on NCC Token Grabber in chrome://extensions.

Install manually

  1. Download the zip, then right-click it and choose Extract All. Move the extracted ncc-token-grabber folder somewhere it can stay, such as Documents. Chrome keeps loading it from there.
  2. In Chrome, go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the ncc-token-grabber folder.
  4. Click the puzzle-piece icon in the toolbar and pin NCC Token Grabber so it's easy to reach.

Use

  • Open your NCC (thrio.io) tab and sign in as usual.
  • Click the NCC Token Grabber toolbar icon. It reads the token from that tab and copies a bundle — tenant name, tenant ID, cluster, URL and token — to your clipboard.
  • Click Show to see the bundle before pasting it.

The token is your own live session token, the same one your browser already sends to NCC. It is read only when you click the icon, stays on your clipboard, and is not sent anywhere. Treat it like a password: it grants access to your NCC session until it expires, so only paste it where you mean to, and don't share it with anyone you wouldn't give your sign-in to.

Updating

Easiest: run the installer again (Win+R command or zip above), then click the reload arrow in chrome://extensions. Or by hand: Download the new zip, extract it, and copy its files over your existing folder. Then click the reload arrow on the extension in chrome://extensions.

Works in Google Chrome and Microsoft Edge.
